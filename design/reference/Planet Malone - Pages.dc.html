Context

NextGen is a ground-up rebuild of the platform. It needed one design system that design and engineering could both trust, and components that were accessible by default rather than by effort.

Draft: Sean to add the starting state (component count, where the old components came from, known accessibility gaps).

My role and scope

  • Authored the Figma design system: tokens, oklch palette, full React Aria component set.
  • Owned design-system and accessibility decisions for NextGen.
  • Led the component migration inside a six-engineer epic.

Key decisions and trade-offs

Before
shadcn / RadixFast to start. Behaviour and styling copied into the codebase, so every team owned its own fork.
Chose
React Aria ComponentsAccessibility and internationalisation behaviour maintained upstream; we own only the styling layer.

The cost was a migration mid-build. I wrote it up as an ADR, including what we'd lose, and made the case before the epic started rather than after.

Draft: confirm the trade-off wording and link the ADR.

How I brought people along

Established one rule with design: handoffs must match the design system. If a screen needs something the system doesn't have, that becomes a system change first.

“Guardian of quality, consistency and sustainability.”Team lead, NextGen

Outcomes

Full setReact Aria component set, designed and built
6engineers migrated inside one epic
1 ruledesign handoffs match the system
